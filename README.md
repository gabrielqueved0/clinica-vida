# Clínica Vida+

Sistema de cadastro e busca de pacientes feito em Python, rodando no terminal.

## O que ele faz

- Cadastra pacientes (nome, idade e telefone)
- Busca paciente pelo nome
- Lista todos os pacientes cadastrados
- Mostra estatísticas: total, idade média, paciente mais novo e mais velho

## Como rodar

1. Instale o Python 3
2. Baixe o arquivo `Projeto.py`
3. No terminal, rode: `python Projeto.py`
